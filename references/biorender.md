# BioRender 原生画布绘制

用于用户要求在 BioRender 中使用官方图库绘图、临摹或修改现有画布。沿用 SKILL.md 的连接、后台窗口及退出规则。本流程通过已登录网页操作原生对象；不代表接入官方图库 API、运行 GitHub 绘图 skill 或调用 BioRender AI。

## 先确定当前任务的画布

- 复用本任务已核对的 illustration 页面和同一连接；不要为了测试新建 illustration。已有任务入口只保存在任务目录，不把 targetId、socket、账户、画布 URL 或本地参考图路径写入 skill。
- 核对本次明确授权的画布和修改范围。删除、清空或覆盖难以恢复的内容时，若尚未取得相应授权，先列明对象、操作及影响并等待确认；已有明确授权不重复确认。清空前尽可能保留原图预览；预览不是可编辑工程备份，不声称可以完整恢复工程。
- 限额是账户当时的状态，不是固定产品参数。遇到新建限额，先判断是否可以按已有授权复用当前画布；没有授权则说明需要选择的画布。不自动试用、升级、付费、清理其他图或调用 AI。
- 将参考图拆成有限对象清单：官方图标、原生形状、箭头、普通文字、需独立样式的短文字。先规划相对位置、字号与色值，再执行。忠实保留科学内容，不补造实验结果。

## 连接与复用脚本

正常连接示意（参数以当次查询为准）：

```bash
browser-bg serve --browser chrome --connection fixed --port 9228 \
  --target <当次核对的目标ID> --origin https://app.biorender.com
python3 scripts/biorender.py --socket <本次socket> inspect
```

`scripts/` 相对于本 skill 目录。`biorender.py` 复用当前 bridge，提供 `Client` 的读状态、有界等待、定位点击、拖动、键盘输入和预览读取；命令行默认没有清空、新建、绘图或导出操作。首次读取时在该 Client 内绑定当前 illustration 路径，后续发现页面换到其他图则停止，不把路径写入全局配置。导入后调用的写操作仍服从任务授权。`inspect` 的 `dialogImagePresent` 只表示页面存在对话框图片，不证明官方导出窗口已经核对。

```python
from biorender import Client  # 将本 skill/scripts 加入 sys.path 后导入
ui = Client(socket_path)     # 由当前 serve 返回，不复用历史 socket
before = ui.inspect()
ui.click('button[data-testid="content-panel-tab-icons"]')
# 先检查当前页面，再填写已存在的搜索框。
ui.fill('textarea[data-testid="asset-search-input"]', search_term)
```

bridge 的新增 `cdp` 操作只接受 `Input.dispatchMouseEvent`、`Input.dispatchKeyEvent`、`Input.insertText`、`Page.getLayoutMetrics`，通过已有附着会话发送，并在每次操作前检查 origin。没有开放任意 CDP、窗口激活、浏览器关闭或 Cookie 接口。

## 高效的顺序与确认方法

1. **画布。** 设置长宽和背景；尺寸输入后点击 `Apply`，不要以 `Escape` 代替提交。检查属性回读。顶部尺寸文字可能四舍五入，精确尺寸以编辑界面为准。
2. **核心素材。** 找到并验证一个对象后，再调整尺寸、方向和位置；复制已验证的对象来放置重复素材。
3. **文字。** 一开始就拖出足够宽的文本框，再输入和设置字号，减少反复缩放。短语样式不同且字符选择不稳定时，使用独立文本对象并对齐基线。
4. **形状与线。** 最后补充箭头、连接线、框和底色；设置填充、描边与宽度，检查层次关系。
5. **核对。** 每个有意义的阶段检查对象数、选中对象及预览。一个对象插入结果未确认时，不把相同动作再发一次。

在每次动作后等待相应可观察状态，而不是密集发送命令：搜索结果已更新、对象数符合预期、选中框出现、属性回读改变、文本编辑器取得焦点。`Client.wait()` 只重试读取，超时后先诊断，不能自动重放写操作。复杂图标可能包含多个对象，不能假定插入一个图标只增加 1。

以下选择器为 2026-11-08 实测线索，使用前核对当前 DOM；不存在或不唯一时重新定位，不直接照抄历史坐标。

| 操作 | 页面线索与容易踩的坑 |
| --- | --- |
| 图库搜索 | 点击侧栏 Search 后，寻找 `textarea[data-testid="asset-search-input"]`。编辑属性面板打开时，同名 testid 可能是 DIV 菜单入口，不能对它调用 `select()`。 |
| 只选图标 | 先选 `content-panel-tab-icons`。All 视图里图标和模板 DOM 可能都存在，历史卡片坐标会点中整套模板。 |
| 插入图标 | 核对 `.asset-container` 的可见卡片、名称/预览及鼠标命中元素，再双击或拖入。选中框和对象计数确认后继续；不要只凭 CDP 成功返回判断插入成功。 |
| 尺寸 | `transform-width`、`transform-height`；数值使用当前单位，Enter 提交并回读实际边框。不要用 Tab 后立刻 Escape 的组合赌更新已生效。 |
| 旋转 | `transform-rotation`；镜像通过 Flip 菜单的 horizontal/vertical 项。 |
| 文字字号 | `properties-panel-text-size-input-field`。普通属性输入必须确认焦点在该输入框，防止 Ctrl+A 实际选中整张画布。 |
| 文本样式 | `select-option-bold`、`select-option-italic`、`select-option-center`。确认是整对象还是字符选区；工具栏存在不代表已经进入字符编辑。 |
| 填充与边框 | `input[name="fieldColor"]` 可能有两个，分别核对 Fill/Stroke 上下文；`properties-panel-border-width` 控制边框。不要只用第一个匹配项代表任意颜色。 |
| 形状 | 侧栏 Shapes 菜单悬停到 Shapes/Arrows 后，检查 `shape-tool-mode-*` 的 title，例如 Rounded Rectangle、Hexagon、Thin Block Arrow。 |

### 焦点、文字和复制

- 新文本框创建后，等待 `document.activeElement` 是可编辑的 Fabric textarea，再输入。页面可能保留多个 `textarea[data-fabric-hiddentextarea]`，第一个往往已隐藏；不要用第一个 textarea 的空值认定文字丢失。`Client.insert_text()` 要求实际焦点匹配指定选择器。
- 属性输入与文字编辑分别处理。输入后点击空白处结束编辑，再重新选择文本对象设置字号/对齐；以真实画布结果收尾。必要时允许短暂稳定时间（本次文本创建约 2 秒、输入后约 1–2 秒），这只是现场经验，不是完成证据。
- 文本对象的 Transform 宽度会连字号一起缩放。需要增加文本容器宽度时，拖左右边中点控制柄；需要调整高度时，拖上下边中点。四角控制柄会缩放，不能作为增加文字行宽的替代。
- `Escape` 可能结束编辑、取消操作或删除空文本框。不要把它当作适用于所有浮层的关闭按钮。
- 复制前重新点击画布中要复制的对象，确认焦点不在字号/旋转等输入框；否则 Ctrl+C 可能复制数值。粘贴后确认对象数和新的选中框，再移动，避免实际移动了原对象。
- 混合样式优先采用经过验证的方法。若无法确认字符选区，把 `Vhl` 等基因名独立为斜体对象，其余说明为正体；检查基线和连接处间距。阳性细胞标签保留 `CD8⁺ T cells` 这样的上标与空格。

### 定位与拖动

- `Client.inspect()` 返回 CSS 视口尺寸、缩放、当前 `.move-control` 边框和可用的画布矩阵。使用实际 DOM 边框定位选中对象和控制柄；窗口、侧栏或缩放改变后重新读取。
- `click_at()` 与 `drag()` 接收当前视口的 CSS 像素，不是导出图片像素、设备像素或英寸。上一张图的偏移量、画布中心、缩放和参考图宽高都不能直接复用。
- 在当前画布尺寸与矩阵均核对后，才将参考图的相对位置映射到画布。先移动一个已知对象，并用预览校准映射，再批量放置。原生形状的控制框可能含额外边距，不把它当作形状可见边界。
- `Client.element()` 会拒绝被遮挡或在视口外的元素，避免把隐藏卡片当作可点击目标。拖动异常后检查鼠标释放和对象状态，再继续，不重复整批操作。

## 预览与交付

- 本次最小化 Chrome 上 `Page.captureScreenshot` 两种模式均超时；CanvasKit 主 canvas 的 `toDataURL()` 得到空/黑图。遇到相同表现不要反复重试，也不要激活窗口解决后台截图。
- 优先用站内 Export 窗口的官方预览检查画布；缩略图只能检查粗略布局。打开预览后等待图像加载和稳定，初始图片可能是空白或上一状态。
- 已经打开官方导出窗口时，先检查当前 DOM，核对它确为官方 Export 窗口，并记录该框及其内部预览图的精确选择器。选择器没有通用默认值；不能用未经核对的任意弹窗替代。然后运行：

```bash
python3 scripts/biorender.py --socket <本次socket> preview --output <任务目录的新PNG路径> \
  --dialog-selector '<本轮核对的导出对话框选择器>' \
  --image-selector '<该框内部核对过的预览图选择器>'
```

- 该命令在每轮读取时确认显式选择器对应唯一可见对话框及框内唯一可见图片，缺失或歧义时停止；它不自行证明窗口用途，官方 Export 身份由调用者先核对。命令不打开/关闭窗口，不发起导出，不改变分辨率或水印。读取成功、PNG 格式有效、连续图像相同，都不等于内容正确：必须实际查看完整图片，核对最后的改动、对象数量、标签、裁切、重叠和字号。过大的预览超出 bridge 大小限制时缩小读取范围，不调高全局上限或抽取图库资源绕过导出。
- 内部预览仅用于核对，不将其冒称为正式导出、无水印交付或具有发表许可的文件。用户需要文件时走官网正常 Export 流程，遵守账户显示的权限和水印。
- 未获用户明确导出要求时，可直接交付网页中的可编辑画布。检查没有错误提示和未完成对话框，关闭任务连接并确认退出，保留用户页面。没有观察到保存提示或重载验证时，不额外声称“云端保存已验证”。
